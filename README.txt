# Architekten – Projekte

Die Seite besteht aus:
- index.html
- style.css
- script.js
- images/

## Bilder einsetzen

Im `script.js` stehen die Projekte.

Beispiel:

images: [
  "images/hotel-1.jpg",
  "images/hotel-2.jpg",
  "images/hotel-3.jpg"
]

Lege deine echten Bilder mit genau diesen Dateinamen in den Ordner `images`.

## Verhalten

1. Kategorie anklicken → Galerie wird gefiltert.
2. Auf ein Foto klicken → weiße Projektansicht öffnet sich auf derselben Seite.
3. Großes Bild wird angezeigt.
4. Links/rechts befinden sich Pfeile.
5. Unter dem Bild stehen Projektbeschreibung und Projektdaten.
6. Weitere Projektbilder erscheinen als kleine Vorschaubilder.
7. X schließt die Projektansicht.
8. Tastatur: ← / → zum Blättern, ESC zum Schließen.

Die Demo funktioniert auch ohne echte Bilder, weil automatisch neutrale Platzhalter angezeigt werden.
